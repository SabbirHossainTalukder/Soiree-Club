# Soirée Club website

Static site: `index.html` (no build step). Add a founder photo named `founder.jpg` in this folder (optional).

## Deploy on Vercel
1. Put this folder on GitHub (or run `npm i -g vercel` then `vercel` inside the folder).
2. On vercel.com choose Add New > Project, import the repo.
3. Framework Preset: Other. Leave build command and output directory empty. Click Deploy.

## Edit before publishing
Search `index.html` for: `hello@soireeclub.com`, `+880 1XXX`, `Founder Name`, event cards, plan prices.
